## Common Prompt
I have two folders ('../original/Raw benthic raster files', '../original/Raw geomorphic raster tiles') each  with 5 zip files that each contain Geotiff images that cover northern Australia at high resolution (10m). The folders only contain zip files that we want to process, and the zip files only contain Geotiff images that we want to process. Example file names for the zips: NESPN_gulf_benthic_clean2_tiles.zip, NESPN_sharkbay_benthic_clean2c.zip. Example filenames for extracted Geotiffs: gulf_benthic_clean2d-0000000000-0000000000.tif, nwest_benthic_clean2g-0000000000-0000131072.tif. These Geotiffs correspond to habitat mapping with categorical classifications. The full study area is covered by a patchwork of images. In some cases they overlap because they were developed by different models. In some cases the images are full of zero (nodata) because they correspond to land or blank open ocean. 

The challenge is to mosaic them together converting them to a single raster with a pyramid overview and compression. I did a rough version in QGIS using by converting them to a virtual raster, then exporting the raster. There were two problems. Most of the data files are 8 bit, but two of them were 16 bit and so could not be included in the virtual raster. Secondly the value 0 is not marked as nodata in the source GeoTiffs and so in areas where there was overlap when the virtual raster was created it lead to the zero value being taken as the output value instead the actual data. This lead to patches of data being missing. 

I was thinking the workflow could use the following workflow:
1. There are two folders of zips to process (Raw benthic raster files and Raw geomorphic raster tiles). Process each folder separately. Unzip all of the zip files in each folder into a working folder (working/raw/benthic and working/raw/geomorphic)
1. Discover all the extract GeoTiff images in the folder being processed (there are about 30 of them). 
2. Determine if the GeoTiff image is blank (full of zeros). This is about half the images. If so then don't keep processing that file. This is to save on further processing time.
3. Set the nodata value to zero. This could be a process where we recreate the file into a working folder (working/raw-patched/benthic, working/raw-patched/geomorphic) with the correct no-data value. We should also set the output to be 8 bit to standardise the data format. 
4. Convert to a virtual raster to combine all the geotiffs from the working directory and export as a single image with pyramids, or maybe perform a direct merge without the virtual raster. The images are large and thus will not fit in memory. The pyramid subsets need to use mode instead of average because the values are categorical. The output and the pyramid should be LZW compressed. Save the result to 'NW_NESP-MaC-3-17_Shallow-habitat_Benthic.tif' and 'NW_NESP-MaC-3-17_Shallow-habitat_Geomorphic.tif'.
The processing will be slow (several hours), so the script should show progress.
Prior to creating this script do you have any clarifying questions?
